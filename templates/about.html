About CellBase

An open metadata dataset of EV battery components, built for AI research and engineering education.

Project Overview

CellBase is a structured, annotated collection of metadata and images covering the core components of electric vehicle battery packs. It was developed as a Computer Science final year project (CS3IP) at Aston University.

The dataset addresses a clear gap in publicly available resources: while EV battery research is growing rapidly, there is no open, component-level metadata repository formatted for both human navigation and AI training pipelines. CellBase fills that gap.

What the Dataset Contains

🔋Cells
🖥️BMS Units
🔌Connectors
⚡Cables
➖Busbars
🛡️Casings
🔩Hardware

Each entry includes: component ID, type, manufacturer, technical specifications, vehicle associations, image, source URL, license, and notes. All entries are validated against a JSON Schema for consistency.

Research Applications

  • AI / ML training — component classification, object detection, condition monitoring
  • Second-life battery research — identifying and cataloguing components for reuse
  • Engineering education — a reference resource for EV battery system design
  • Automotive diagnostics — structured metadata for battery health analysis tools
